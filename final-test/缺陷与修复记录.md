# 缺陷与修复记录

本文档用于记录 `final-test` 全量测试过程中发现的 BUG、定位过程、修复结果和回归验证结论。所有缺陷必须保留复现证据；所有修复必须有对应回归测试。

## 记录规范

| 字段 | 要求 |
|---|---|
| 缺陷编号 | 使用 `BUG-FE-xxx`、`BUG-BE-xxx`、`BUG-TEST-xxx` |
| 严重级别 | `P0` 阻断主流程；`P1` 核心功能不可用；`P2` 重要功能异常；`P3` 轻微问题 |
| 状态 | `待复现`、`已复现`、`定位中`、`已修复待回归`、`回归通过`、`暂缓` |
| 证据 | 截图、Selenium/JUnit 报告、浏览器控制台、网络请求、后端日志、接口响应 |
| 修复记录 | 写明修改文件、原因、修复策略、验证命令和回归结果 |
